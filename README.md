Entry for the [One Letter: Coffee or Tea](https://make.fun/c/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) bounty on make.fun.

## The entry

**A — coffee.**

One letter, nothing else. The spec allows exactly one letter: A for coffee,
B for tea, with no word, no explanation, no punctuation. `main.py` writes
that single letter to `/output/entry.txt`.

## Why A

Coffee is the more vivid drink — bitter, steaming, the jolt that starts the
morning — and the funnier one (nobody jokes "don't talk to me before my tea").
The letter A itself is first, top grade, and stands for "awake": coffee wakes
you up. Tea is calm and polite; coffee is alive. A is the bolder, truer,
more alive answer.

## Run

```sh
python3 main.py   # writes /output/entry.txt containing exactly "A"
```

Pure Python standard library, no third-party dependencies.
